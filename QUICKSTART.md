# 🚀 Быстрый старт для коллег

## За 5 минут до запуска

### 1. Установите необходимые программы

#### Node.js (для запуска бота)
- Скачать: https://nodejs.org/
- Установите LTS версию
- **ВАЖНО**: При установке просто нажимайте "Next" везде

#### Python (для генерации карт, если нужно)
- Скачать: https://www.python.org/downloads/
- **ВАЖНО**: При установке поставьте галочку "Add Python to PATH"

### 2. Откройте проект

1. Скачайте VS Code: https://code.visualstudio.com/
2. Откройте VS Code
3. `Файл` → `Открыть папку` → выберите папку `testing_bot_2`

### 3. Установите зависимости

В VS Code:
- Нажмите `` Ctrl+` `` (открыть терминал)
- Введите команду:

```bash
npm install
```

Подождите 1-2 минуты, пока установятся библиотеки.

### 4. Запустите бота

В том же терминале введите:

```bash
npm start
```

Вы увидите:
```
🤖 Бот запущен!
✅ Бот готов к работе!
```

### 5. Проверьте работу

1. Откройте Telegram
2. Найдите вашего бота
3. Напишите `/start`
4. Задайте вопрос, например: "Что меня ждет в 2026 году?"

## ⚠️ ВАЖНО ПЕРЕД ЗАПУСКОМ

### Заполните интерпретации карт

Откройте файл `tarot_interpretations.json` и замените все "ЗАПОЛНИТЕ:" на реальные интерпретации.

**Пример:**
```json
"upright": "Новые начинания, приключения, оптимизм"
```

### Заполните маркетинговые сообщения

Откройте файл `marketing_messages.json` и добавьте ваши тексты.

**Пример:**
```json
"message": "💰 Узнай больше о финансовой грамотности в нашем курсе!"
```

## 🛑 Остановка бота

В терминале нажмите `Ctrl+C`

## 🔄 Перезапуск бота

После внесения изменений:
1. Остановите бота (`Ctrl+C`)
2. Запустите снова (`npm start`)

## ❓ Что-то не работает?

### Бот не запускается
```bash
npm install
npm start
```

### Нет изображений карт
```bash
pip install pillow
python generate_cards.py
```

### Другие проблемы
Посмотрите в терминал - там будут сообщения об ошибках.

## 📞 Горячая линия

Если совсем ничего не работает:
1. Закройте VS Code
2. Удалите папку `node_modules`
3. Откройте VS Code снова
4. Выполните `npm install`
5. Выполните `npm start`
