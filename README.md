# 🔮 Телеграм-бот для гадания на таро

Бот для гадания на таро с использованием Claude Haiku 4.5 для интерпретации карт.

## 📋 Возможности

- 🎴 Раскладка таро из 3 карт (прошлое-настоящее-будущее)
- 🤖 Автоматическая верификация вопросов (исключение политических и этически нагруженных тем)
- 🔄 Переформулирование сложных вопросов в нейтральные
- 💡 Умная интерпретация карт с помощью Claude Haiku 4.5
- 🖼 Создание коллажей из выпавших карт
- 📚 Маркетинговые блоки с рекомендациями курсов по категориям
- 🔁 Возможность задать несколько вопросов подряд

## 🛠 Установка на Windows

### Шаг 1: Установите Node.js

1. Скачайте Node.js с официального сайта: https://nodejs.org/
2. Установите версию LTS (Long Term Support)
3. Проверьте установку, открыв командную строку (Win+R → cmd) и выполнив:
   ```
   node --version
   npm --version
   ```

### Шаг 2: Установите Python (для генерации карт)

1. Скачайте Python с официального сайта: https://www.python.org/downloads/
2. При установке обязательно отметьте "Add Python to PATH"
3. Проверьте установку:
   ```
   python --version
   pip --version
   ```

### Шаг 3: Скопируйте репозиторий

1. Откройте VS Code
2. Нажмите `Ctrl+Shift+P` → `Git: Clone`
3. Введите URL репозитория
4. Выберите папку для клонирования

Или через командную строку:
```bash
git clone <URL_репозитория>
cd testing_bot_2
```

### Шаг 4: Установите зависимости

Откройте терминал в VS Code (Терминал → Новый терминал) и выполните:

```bash
npm install
```

### Шаг 5: Сгенерируйте изображения карт таро

```bash
pip install pillow
python generate_cards.py
```

Это создаст папку `tarot_cards` с 78 картами.

### Шаг 6: Настройте конфигурацию

Файл `.env` уже настроен с токенами. Если нужно изменить:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
ANTHROPIC_API_KEY=ваш_ключ_anthropic
CLAUDE_MODEL=claude-haiku-4-5
```

### Шаг 7: Заполните интерпретации и маркетинговые сообщения

#### tarot_interpretations.json

Откройте файл `tarot_interpretations.json` и замените все "ЗАПОЛНИТЕ:" на ваши интерпретации карт.

Пример:
```json
{
  "id": 0,
  "name": "Шут",
  "upright": "Новые начинания, спонтанность, свобода, оптимизм",
  "reversed": "Безрассудство, отсутствие направления, хаос"
}
```

#### marketing_messages.json

Откройте файл `marketing_messages.json` и добавьте ваши маркетинговые тексты.

Пример:
```json
{
  "money": {
    "keywords": ["деньги", "финансы", "доход"],
    "message": "💰 Хочешь научиться управлять своими финансами? Пройди курс 'Деньги' в Учебнике!",
    "url": "https://t-j.ru/pro/#category4"
  }
}
```

## 🚀 Запуск бота

В терминале VS Code выполните:

```bash
npm start
```

Вы увидите сообщение:
```
🤖 Бот запущен!
✅ Бот готов к работе!
```

Теперь откройте Telegram и напишите вашему боту `/start`

## 🎯 Как работает бот

1. **Приветствие** (`/start`) - бот приветствует пользователя и объясняет правила
2. **Получение вопроса** - пользователь задает личный вопрос про 2026 год
3. **Верификация** - Claude Haiku проверяет вопрос:
   - Если политический/этический → отказ
   - Если можно переформулировать → переформулирует
   - Если нормальный → принимает
4. **Раскладка карт** - вытягивает 3 случайные карты (с возможностью переворота)
5. **Создание коллажа** - создает изображение с 3 картами
6. **Интерпретация** - Claude Haiku создает персонализированную интерпретацию
7. **Отправка результата** - пользователь получает:
   - Коллаж с картами
   - Список выпавших карт
   - Интерпретацию
   - Маркетинговый блок
   - Кнопку "Задать ещё вопрос"

## 🔧 Категории вопросов

Бот автоматически определяет категорию вопроса и подбирает соответствующий курс:

- 💰 **Деньги**: финансы, доход, зарплата
- 🌟 **Жизнь**: судьба, будущее, счастье
- 🏥 **Здоровье**: болезни, самочувствие
- 💼 **Работа**: карьера, бизнес, увольнение
- 🏠 **Дом и быт**: ремонт, хозяйство
- ❤️ **Отношения**: любовь, партнер, семья
- 👶 **Дети**: воспитание, родительство
- 🚗 **Авто**: автомобиль, транспорт
- 🏢 **Недвижимость**: квартира, ипотека
- 📚 **Другое**: все остальное

## 🐛 Устранение проблем

### Ошибка "Cannot find module"
```bash
npm install
```

### Ошибка при создании коллажа
Убедитесь, что папка `tarot_cards` содержит все 78 изображений:
```bash
python generate_cards.py
```

### Бот не отвечает
1. Проверьте, что токен бота правильный в `.env`
2. Проверьте интернет-соединение
3. Посмотрите логи в консоли

### Claude API не работает
1. Проверьте правильность API ключа в `.env`
2. Проверьте баланс аккаунта Anthropic
3. Убедитесь, что модель `claude-haiku-4-5` доступна

## 📝 Примеры вопросов

**Хорошие вопросы** (принимаются):
- Уволят ли меня в 2026 году?
- Что мне ждать от новых отношений?
- Какие перемены ждут меня в карьере?
- Будет ли у меня прибавка к зарплате?

**Плохие вопросы** (отклоняются):
- Закончится ли война в 2026?
- Кто победит на выборах?
- Умрет ли Путин?

**Вопросы с переформулированием**:
- "Отправят ли меня на СВО?" → "Где я проведу следующий год?"

## 🔄 Обновление изображений карт

Когда у вас будут готовы настоящие изображения карт (960×1658):

1. Замените файлы в папке `tarot_cards/`
2. Сохраните названия файлов: `major_0.png`, `wands_ace.png` и т.д.
3. Перезапустите бота
